This verifier release is derived from the internal `zkdtvm-suite` repository:

- branch: `banjie-dev`
- commit: `82a57cadf6921e4fb45181d98f1a5af0148ab491`
- snapshot date: 2026-08-28

The vendored snapshot contains only the `sp1` and `WHIR-pcs` package dependency
closure required to build this verifier and regenerate its Fibonacci fixture.
Unrelated examples, patch-testing projects, internal workflow material, and
development tooling are excluded. The `Plonky3` tree is also excluded; its
required packages are resolved from crates.io as exact `dt-p3` version `0.8.0`
dependencies.

The release fixture is generated by
`vendor/zkdtvm-suite/sp1/examples/fibonacci/script/bin/export_verifier_fixture.rs`.
The `include_elf!("fibonacci-program")` call builds the guest from the vendored
source before `ProverClient::setup` derives the full program verifying key. The
generator records the resulting ELF SHA-256 and the suite commit in
`fixture-metadata.json` so that `vk.bin` and `vk-full.bin` can be traced to the
exact ELF used for setup.
